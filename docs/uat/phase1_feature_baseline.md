# เอกสารฐานข้อมูลคุณสมบัติระบบ ระยะที่ 1 (Phase 1 Feature Baseline)

> **โครงการ:** แพลตฟอร์มการเรียนรู้ผ่านสื่ออิเล็กทรอนิกส์ (E-Learning Platform)  
> **เวอร์ชัน Baseline:** 1.0 (อ้างอิง Feature List 10 Modules ต้นฉบับ)  
> **วันที่จัดทำ:** 28 ตุลาคม 2026  
> **สถานะการตรวจสอบ:** Codebase Verified (ตรวจสอบเทียบกับโค้ดจริงใน Repository)

---

## 1. คำอธิบายเอกสารและขอบเขตหลัก (Document Context & Scope)

เอกสารฉบับนี้ใช้เป็น **Baseline หลัก** สำหรับการตรวจสอบและประเมินระบบ E-Learning Platform ระยะที่ 1 (Phase 1) โดยรวบรวมรายการคุณสมบัติ (Feature List) ทั้งหมด 10 โมดูล รวม **61 รายการ (Feature / Sub-Feature)** จากเอกสารต้นฉบับของผู้ใช้งานอย่างครบถ้วน ไม่มีการตัดทอน หรือแก้ไขรหัส Feature ID ใด ๆ

### การจัดสรร Scope ตามเอกสารข้อกำหนดความต้องการซอฟต์แวร์ (SRS v2.4):
* **Phase 1 Scope (ระยะที่ 1):** Authentication & Access Control Security (Module 1), LMS Core & Content Management (Module 2), Admin System & Security Management (Module 9)
* **Phase 2 Scope (ระยะที่ 2):** Exercise & Interactive Task System (Module 8.1), Post-Lesson Quiz (Module 8.2), Quiz Configuration (Module 8.3), Results & Feedback (Module 8.4), Progress Tracking & Lesson Unlocking (Module 4.1, 4.2), Single-time XP Reward (Module 5.1)
* **Phase 3 / Future Scope (นอกขอบเขต Phase 1 & 2):** Live Streaming (Module 3), Virtual Lab & Simulator (Module 7), Full Gamification Engine (Module 5.2 - 5.7), Story Engine (Module 6), AI Assistant (Module 10)
